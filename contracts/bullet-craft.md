# STAR bullet 工厂

> 目标：把用户提供的粗糙事实（"做过 X"）改写成**有动作、有产出、可核实**的简历 bullet。
> 只做**翻译与重组**，不做发明——bullet 里每个事实都必须能在素材（profile.yaml / 用户回答）里找到依据。

## 一、STAR 结构（写 bullet 的思维框架）

| 要素 | 含义 | 在 bullet 里的位置 |
|------|------|--------------------|
| S 情境 | 什么背景/问题 | 可省略或融进开头（简历不写背景故事） |
| T 任务 | 你的目标 | 通常融进动词短语 |
| A 动作 | **你做了什么**（最重要） | 动词开头 + 技术/方法 |
| R 结果 | 产出/效果/规模 | 句尾，能量化就量化 |

单条 bullet 的公式：**`动作动词 + 对象/系统 + 技术/方法 + 结果/规模`**

```
✅ 基于 Spring Boot 实现图书借阅后端服务（动词+对象+技术），接口响应时间下降约 30%（结果）
✅ 用 pandas 清理 10 万行销售数据并产出月度趋势图（动词+对象+技术+产出）
❌ 参与图书管理系统项目（无动作、无产出）
❌ 负责后端开发（无对象、无技术、无结果）
```

## 二、动作动词库（按意图分类，选一个贴合事实的）

| 意图 | 动词 |
|------|------|
| 从零构建 | 设计、搭建、实现、开发、构建、落地 |
| 集成接入 | 集成、接入、对接、迁移、改造、二次开发 |
| 分析解决 | 排查、定位、优化、重构、解决、降低、提升 |
| 数据处理 | 清洗、分析、统计、建模、可视化、挖掘 |
| 组织协调 | 组织、统筹、协调、主持、带队、培训 |
| 文档沉淀 | 沉淀、编写、输出、总结、分享 |

**强度规则**：
- 用户原话是"参与/协助"→ 最多用"参与/协助"，**禁止**升格为"负责/主导"（见 SKILL.md 改写红线）
- 用户确实独立完成 → 用"独立实现/从零搭建"
- 带人做过 → 用"带领 N 人小组"（人数必须来自用户陈述）

## 三、量化的三种写法（没有数字就用产出物替代）

1. **数字**：`下降约 30%` / `覆盖 12 个页面` / `500+ 人参与`
   —— 数字必须来自用户/素材，**禁止编造**；模糊区间可写"约"
2. **规模**：`6 张表的 CRUD` / `10 万行数据` / `3 个微服务`
   —— 描述工作量的客观存在，比百分比更安全
3. **产出物**：`产出 README 与演示视频` / `代码已开源（GitHub）` / `通过课程验收`
   —— 实在没有数字时，用可见产出收尾

> 夸大词红线：`精通`、`显著提升`、`大幅优化`、`业界领先`、`顶尖` 等无数据支撑的表述
> 不得写入 bullet（`validate` 会抓，见 `resume.mjs` 内容检查）。

## 四、改写示例（保持事实，提升表达）

| 原始素材 | 改写 bullet | 技巧 |
|---|---|---|
| "做过一个课设，图书管理系统，Java 写的" | Java 课程设计：实现图书借阅管理系统，含借阅/归还/超期统计等 6 个核心功能模块 | 补规模（6 模块），定语划范围 |
| "毕设复现了 Transformer，用 PyTorch" | 毕业设计：用 PyTorch 从零实现注意力机制与编码器-解码器，在小规模翻译任务上复现基线效果 | 技术细节具体化 + 产出 |
| "在社团组织过活动" | 组织校级迎新晚会（参与 500+ 人），统筹 8 人宣传组完成物料设计与现场执行 | 量化规模 + 拆解动作 |
| "跟教程做过 TODO 项目，自己加了分类" | 实现待办事项 Web 应用（React + FastAPI），在教程基础上自行扩展标签分类与到期提醒 | 突出"自行扩展"= 学习能力 |
| "帮实验室维护网站" | 维护实验室设备管理网站（Vue + Spring Boot），修复 5 个历史 bug 并新增设备借用登记功能 | 维护也写成有产出的动作 |

## 五、一条 bullet 的自检清单（写完逐条过）

- [ ] 动词开头？且强度与用户原话一致（没把"参与"写成"主导"）？
- [ ] 有技术栈/方法（JD 关键词优先用 JD 的叫法，见 `jd-alignment.md`）？
- [ ] 有产出/结果/规模（数字、规模或产出物至少占一个）？
- [ ] 每个事实都能在素材里找到依据？（找不到就删）
- [ ] 长度 ≤ 120 字符（`validate` 会警告）？排第一的 bullet 是否最相关？
